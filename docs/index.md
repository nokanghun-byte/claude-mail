# Claude 메일 · Claude Mail

Claude 데스크톱 앱 안에서 Gmail과 IMAP을 지원하는 모든 메일(네이버·카카오·다음·아웃룩·회사 메일 등)을 한 화면에서 읽고 답장하는 웹메일 페이지입니다.

A webmail page inside the Claude desktop app for Gmail and any IMAP mailbox (Naver, Kakao, Daum, Outlook, company mail, and more).

- 설치 방법과 기능 · Install & features: [README](https://github.com/nokanghun-byte/claude-mail#readme)
- [개인정보처리방침 · Privacy Policy](privacy.md)

큰 첨부파일은 사용자 본인의 Google Drive에 올려 링크로 보냅니다(`drive.file` 권한, 이 앱이 올린 파일만 접근).
Large attachments are uploaded to the user's own Google Drive and sent as a link (`drive.file` scope: only files this app uploaded).
